# PLATEAUデータをマイクラのワールドデータにする裏技を見つけた！

## 概要

11/29–30 に信州大学農学部で開催されたオープンソースGISの国内カンファレンス「FOSS4G SHINSHU 2025」に参加・登壇するために、久々に伊那谷にやってきた。 最終日のハンズオンデーでは、合同会社ちいもりの杉本健輔さんによる「親子でマイクラ！

## 重要ポイント

- 11/29–30 に信州大学農学部で開催されたオープンソースGISの国内カンファレンス「FOSS4G SHINSHU 2025」に参加・登壇するために、久々に伊那谷にやってきた。
- ハンズオンでは、QGISでのデータ下準備 → WorldPainter → マインクラフト という３段構成でワールドデータの構築を丁寧に説明していただいた。
- 特に、本来のDEMデータ生成工程の逆であるDEMからDSMへの変換とNull値のフィルタ処理など、PLATEAUやDEM配信側の立場としては、いかに建物や植物の高さ分を取り除くかを重視するものの、マイクラ目線だと余計なことせずDSMでデータを出してくれればいい！
- また、WorldPainter にDSMデータをインポート後、Biomes や Layers 設定で、どのような動植物や世界観の調整するかという編集作業は、往年のシムシティやシムアース世代にとっては時間が溶けそうな怖さすら感じる面白さだ。
- 早速、最初にインポートテストを行った東村山市で試してみよう。
- 最終日のハンズオンデーでは、合同会社ちいもりの杉本健輔さんによる「親子でマイクラ！
- DEMとPLATEAUから世界をつくろう。

## 研究室活動としての意味

11/29–30 に信州大学農学部で開催されたオープンソースGISの国内カンファレンス「FOSS4G SHINSHU 2025」に参加・登壇するために、久々に伊那谷にやってきた。 御存知の通り、国土交通省の都市デジタルツインプロジェクト Project PLATEAU は、そのベースデータを CityGML 形式で提供しているため、徐々に変換ツールやその使い勝手が向上しているとはいえ、まだ誰もが自由に使えるレベルとはいえない。
