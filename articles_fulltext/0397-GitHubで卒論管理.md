# GitHubで卒論管理

## 概要

文系の学生が卒業間際に提出する卒業論文って、紙媒体で出力されたレポートが大半をしめる。 そんな中で古橋研究室の卒業論文は一味違う。

## 重要ポイント

- そのためこれからはブログでは卒業制作と呼ぶことにしよう。
- 実は今まで学生が定期的にあげていたブログさえも、そのブログの内容は卒業制作のための研究である。
- これまた驚きの卒業制作の進歩管理はGitHubで行われている。
- 古橋研究室ではGitHubのProjectsで各学生の卒業制作進歩状況を共有し、質問や報告作業にIssuesを使う。
- また私の場合は卒業制作がPWAなため、GitHub Pagesを活用している。
